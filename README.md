# 文件下载站

一个简洁、响应式的静态文件下载站，基于 GitHub Pages 部署。

## 访问地址

https://7878-hub.github.io/download-station/

## 功能

- 📁 文件卡片展示（图标、名称、大小、日期）
- 🔍 实时搜索文件名
- 🏷️ 自动按文件类型分类筛选
- ⬇️ 一键下载
- 📱 响应式设计，手机也能用

## 怎么添加新文件

1. 把文件上传到 `downloads/` 目录
2. 编辑 `files.json`，添加对应条目：
   ```json
   {
       "name": "文件名.扩展名",
       "size": 12345,
       "date": "2026-08-17T13:38:39",
       "path": "downloads/文件名.扩展名"
   }
   ```
3. 提交并推送到 GitHub，等待 1-2 分钟自动部署

## 注意事项

- 单个文件大小限制 100MB
- 仓库总大小建议 1GB 以内
- 大文件建议用网盘链接分享
